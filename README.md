# Data-Science-Notes

Welcome to the **Data-Science-Notes** repository! This repository serves as a comprehensive collection of study materials, handwritten notes, and practical resources for learning and mastering Data Science, Machine Learning, and related technologies.

**Created by: Panchanan sahoo**

## 📚 Repository Structure

This repository is organized into three main sections to help you navigate through the materials seamlessly:

### 1. `Data-Science-Handwritten-Notes`
A collection of detailed, handwritten notes covering core Data Science concepts.
- **Topics Covered:** 
  - Python Fundamentals (Classes, OOPs, RegEx)
  - Libraries (NumPy, Pandas, Matplotlib, Seaborn)
  - Machine Learning Algorithms (Linear Regression, Logistic Regression, Decision Trees, Random Forests, SVM, KNN)
  - Data Cleaning and Feature Engineering

### 2. `DataScience-StudyMaterial`
Extensive study guides and references designed to build a strong foundation in data analytics and scientific computing.
- **Highlights:**
  - In-depth theoretical concepts
  - Interview preparation materials
  - Cheat sheets and quick reference guides
  - Recommended reading books

### 3. `data_science_notes`
Practical coding examples, scripts, and web application implementations.
- **Highlights:**
  - Python programming deep dives
  - Data Visualization (D3.js, Plotly, Leaflet)
  - Web scraping and database integration
  - Web application deployment (Flask, Heroku, HTML/CSS/JS)
  - Statistics and Probability resources

### 4. `archive` (Subject-Wise Reference Library)
A vast, neatly organized collection of cheat sheets, textbooks, and topic-specific guides covering all aspects of data science and software engineering.

## 🚀 Getting Started

To get started with these materials locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/panchanansahoo/Data-Science-Notes.git
   ```
2. Navigate to the section you wish to study and explore the PDFs, markdown notes, and Jupyter Notebooks.
